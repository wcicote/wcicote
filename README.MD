## Abordagem de qualidade

Meu trabalho em QA é guiado por clareza, rastreabilidade e impacto real. Na prática:

- Entender o requisito antes de criar qualquer caso de teste
- Cobrir não só o Happy Path, mas os cenários negativos e de borda que quebram em produção
- Documentar com precisão suficiente para que qualquer pessoa do time reproduza o teste
- Registrar bugs com evidência, severidade, prioridade e contexto para reprodução
- Usar automação onde ela agrega estabilidade — não como fim em si mesma
